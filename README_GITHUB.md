# SARMAT DOORS — Ready 15 final test package

Это финальная тестовая сборка Ready 15 без изменения дизайна и утверждённого PDF-оформления.

## GitHub Pages

Для визуального и функционального теста интерфейса загрузите содержимое этой папки в репозиторий GitHub и включите GitHub Pages для ветки `main`, папки `/ (root)`.

`index.html` находится в корне, `.nojekyll` уже добавлен.

**Важно:** GitHub Pages публикует статические HTML/CSS/JS-файлы. Серверные `/api/pdf` и `/api/order` на GitHub Pages не исполняются. Поэтому на GitHub можно полноценно проверить интерфейс, конфигуратор, несколько позиций, тип «Техническая», примечания и клиентские сценарии; для реального серверного PDF и Telegram используется `server.py` на Render/другом Python-хостинге.

## Локальный / Render тест

```bash
python server.py
```

Откройте `http://localhost:8080`.

Перед реальной отправкой в Telegram задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` через переменные окружения.

## Зафиксированные функции

- Ready 15 — исходное оформление сохранено.
- В одной заявке можно добавлять несколько позиций.
- Для каждой позиции отдельно сохраняются размеры, толщина полотна, толщина коробки, открывание, RAL, фурнитура, доводчик, монтаж и примечание.
- Противопожарные: EI30 / EI60 / EI90 / EI120.
- Техническая дверь: класс EI скрывается/не применяется, антипаника недоступна, используется Fuaro, расчёт по базе EI30.
- Общая конструкционная строка с одной толщиной для всего заказа отсутствует.
- Серверный PDF формируется отдельным endpoint `/api/pdf`.
- После `/api/order` тот же PDF отправляется в Telegram.
- В PDF таблица разбивается на страницы без обрезания строк, с повторением заголовка.
- Утверждённые подпись и круглая печать используются без изменения их пропорций.
