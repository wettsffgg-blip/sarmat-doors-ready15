# SARMAT DOORS READY 15 — финальная проверка

Проверено перед выдачей:

- Конфигуратор сохраняет несколько позиций в одной заявке.
- Для каждой позиции отдельно сохраняются ширина, высота, толщина полотна, толщина коробки, открывание, RAL, фурнитура, доводчик, монтаж и примечание.
- Противопожарная дверь: EI30 / EI60 / EI90 / EI120.
- Техническая дверь: без класса EI; антипаника недоступна; автоматически используется Fuaro; расчёт по базовой цене EI30.
- Общий блок с «базовой толщиной полотна/коробки» из итогового заказа не используется.
- PDF формируется сервером через /api/pdf и скачивается браузером.
- После отправки /api/order формируется тот же PDF и отправляется в Telegram вместе с заявкой.
- В PDF таблица разбивается по страницам с повторением заголовка; строки не обрезаются по вертикали.
- В PDF используются фирменная шапка, дата, подпись и круглая печать; подпись и печать сохранены с правильными пропорциями.
- Проверен тестовый заказ на 60 позиций с разными типами, EI-классами, толщинами, монтажом и примечаниями.
- Синтаксис server.py проверен через py_compile.
