# SARMAT DOORS READY-15 — временный Render-тест

## Что это
Тестовая публикация B2B-сайта с серверным PDF и реальной отправкой заявки в Telegram.

## Развёртывание
1. Загрузите этот проект в приватный GitHub-репозиторий.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml` и создаст Web Service.
4. На первом создании Render попросит значения секретов:
   - `TELEGRAM_BOT_TOKEN` — тестовый токен;
   - `TELEGRAM_CHAT_ID` — рабочий chat_id.
5. После успешного Deploy откройте выданный `https://...onrender.com`.
6. Для проверки сначала откройте `/api/health`. Ожидается JSON с `ok: true` и `telegramConfigured: true`.

## Важно
Токен не хранится в репозитории и не записывается в `render.yaml`; Render рекомендует хранить секреты как environment variables.

Free Web Service подходит для теста, но Render указывает, что бесплатные web services могут автоматически останавливаться после периода бездействия и просыпаться при новом запросе.

После завершения тестов тестовый токен следует отозвать и заменить новым перед публикацией на постоянном хостинге.
