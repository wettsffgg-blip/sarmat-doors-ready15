# SARMAT DOORS B2B READY-15

Исправленная тестовая версия.

## Запуск
1. Установите Python 3.10+ с reportlab.
2. Скопируйте `.env.example` в `.env` и задайте TELEGRAM_BOT_TOKEN. CHAT_ID уже указан для рабочей группы.
3. Запустите `python server.py` или `start.bat`.
4. Откройте http://localhost:8080

## Исправлено
- корректные толщины 1.2/1.5/2.0 и 1.5/2.0/2.5 мм;
- отдельное левое/правое открывание;
- примечание отдельно по каждой позиции и в PDF;
- запрет невалидных размеров/количества;
- защита от несохранённой последней позиции;
- расширенная стандартная палитра RAL без доплаты;
- редкий RAL с отдельным номером и доплатой;
- убрано дублирование доводчика;
- номер и дата заявки;
- сохранение заказа в localStorage;
- настоящий скачиваемый PDF через сервер;
- отправка полного заказа в Telegram через сервер;
- обязательные компания/контакт/телефон;
- тест Telegram только через серверный endpoint;
- документы и каталог вынесены в отдельный раздел.


## Тип двери
- Противопожарная — работает прежний выбор EI30/EI60/EI90/EI120 и прежняя ценовая логика.
- Техническая — классификатор огнестойкости скрывается и не применяется; цена рассчитывается по базе EI30 (коэффициент 1.0).
- Другие типы дверей не добавлялись.
